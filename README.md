# 📦 CoreInventory

CoreInventory is a web-based inventory management platform developed during a hackathon to help businesses efficiently manage products, inventory records, and stock information through a centralized dashboard.

The system is designed to simplify inventory operations by providing an easy-to-use interface for managing products, monitoring stock levels, and maintaining inventory data in an organized manner.

---

# 🚀 Overview

Inventory management is an essential part of any business. Manual inventory tracking can lead to errors, stock mismanagement, and inefficiencies.

CoreInventory provides a digital solution that allows users to manage inventory through a modern dashboard, helping businesses maintain accurate inventory records and improve operational efficiency.

# ⚙️ Installation & Setup

## 1. Clone the Repository

```bash
git clone https://github.com/VanshMirani/CoreInventory.git
```

## 2. Navigate to Project Directory

```bash
cd CoreInventory
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Configure Environment Variables

Create a `.env` file and add:

```env
MONGO_URI=your_database_connection_string
PORT=5000
JWT_SECRET=your_secret_key
```

## 5. Start the Application

```bash
npm start
```

or

```bash
npm run dev
```

## 6. Open in Browser

```text
http://localhost:3000
```
